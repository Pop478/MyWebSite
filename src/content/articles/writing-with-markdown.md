# Writing articles with Markdown

Markdown keeps the writing process close to the content. A plain text file is
easy to edit, review, and keep in version control.

## Start with a clear structure

Use one main heading, then split the subject into short sections. Readers can
scan the page quickly, while the document remains accessible to screen readers.

## Keep metadata useful

The frontmatter at the top of this file is not displayed as body text. It gives
the website a title, description, date, and list of tags for building article
lists and individual pages.
