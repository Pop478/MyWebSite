# Welcome to the article collection

This site stores articles as Markdown files and lets Astro turn them into fast,
static pages at build time.

## Why use a collection?

A collection gives every article the same predictable fields: a title,
description, publication date, and tags. Astro validates this data before the
site is published, so incomplete content is caught early.

## Where to go next

Visit the articles page to browse the latest posts. Each file in this directory
automatically becomes available to the collection.
